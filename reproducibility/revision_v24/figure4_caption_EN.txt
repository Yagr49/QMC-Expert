Figure 4. Matched human and quantitative supervision. (a) Frozen MolFormer embeddings pass through external 768→512→384→256 encoders trained on the same 681 source molecules (377 training, 304 validation; five paired seeds; no SMOTE). Human Good/Bad labels use contrastive training; continuous MIC uses regression. The learned encoders transform the same 105 target QAC salts. CatBoost is fitted separately for each representation, seed and target-training fold, with identical budgets and categorical task codes. Source-encoder weights remain frozen while target-fold labels train CatBoost. (b,c) Cation- and scaffold-held-out errors across four MIC/MBC endpoints. Each violin contains 420 compound–endpoint absolute errors averaged across five source runs; raw MolFormer is one fixed reference. Bars show medians and interquartile ranges; all values and tails are retained. These matched follow-ups exclude OOD and the missing historical Table 2 quantitative checkpoint. Different training objectives limit causal attribution.
