**Material issues found:**

**1. Y-axis label is imprecise (material).**
The axis reads `"Absolute error, log₂(mg/L)"` (script line 105). For Human, Quantitative, and Shuffled human arms each plotted point is the *mean* of absolute errors across 5 source seeds (`n_source_seeds = 5`); for Raw it is a single-seed value (`n_source_seeds = 1`). The label should read **"Mean absolute error, log₂(mg/L)"** to match Figure 3's axis and the `violin_unit` field in the provenance JSON. Using "mean" is also technically correct for Raw (mean of one). The current label understates the aggregation applied to 3 of the 4 arms.

**2. PNG saved at 360 dpi vs Figure 3's 600 dpi (minor but concrete).**
Script line 107: `dpi=360`. Figure 3 uses `dpi=600`. At 180 mm, 360 dpi yields ~2551 px—acceptable for screen, but inconsistent with Figure 3 for submission. Recommend aligning to 600 dpi.

**3. Short caption (filed txt) does not explicitly mark the source/target training boundary (minor clarification gap).**
The required statement "source guidance ends before target decoder training" is implied by "The learned encoders transform the same 105 target QAC salts. CatBoost is fitted separately … for each … target-training fold" but a single explicit sentence such as *"Source-encoder weights are frozen before any target-fold labels are used"* would satisfy the stated clarity requirement unambiguously.

**No invented data, no RMSE distributions substituted for endpoint-error distributions, no OOD in scientific panels, no tail clipping, checkpoint distinction correctly maintained.** Fix items 1 and 3 before submission; item 2 is strongly recommended.
