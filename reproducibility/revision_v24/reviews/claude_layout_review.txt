- Dual arms rendered as two slim vertical columns, same width, same height — visually emphasising parallel architecture.
- A thin horizontal dashed line separates encoder zone from decoder zone; label it **"source guidance ends / target decoder begins"** in 7 pt italic gray.
- MolFormer box carries a **padlock icon** (no gradient update). Encoders carry a **flame icon** (trained). Decoder carries a **Σ** (shared).
- No performance numbers in schematic.

### Caption Distinctions (required text, ≤3 sentences)

> **Figure 4. Human vs. quantitative source guidance on matched data.** Top: frozen MolFormer embeddings feed two independently trained external compact encoders (768→256); human encoder uses contrastive Good/Bad labels, quantitative encoder uses continuous MIC values (MSE); both share a native CatBoost decoder trained on the same 420 QAC endpoints and four MIC-MBC tasks; no MolFormer weights are updated. Bottom: violin densities show per-molecule×endpoint MAE aggregated over 5 paired seeds (681 molecules, 377 train/304 validation, 80 epochs, no SMOTE); this is the completed v5 matched follow-up experiment, distinct from the original full-quantitative multitarget model (higher R² reported in Table S2; that checkpoint is not replicated here). †Shuffled-human control (gray) indicates no significant semantic benefit from human label ordering at this sample size; result is unresolved and warrants larger-scale investigation.

### Design Risks / Scientific Guardrails

| Risk | Guardrail |
|---|---|
| Readers infer violins are 5 independent RMSE points | Caption must state: density = MAE per molecule×endpoint, 5-seed aggregate |
| Human ≈ Quant ≈ Shuffled read as equivalence claim | Do not add significance bars; shuffled null explicitly flagged unresolved |
| Historical Table 2 metrics confused with these violins | Caption explicitly names SI table and states checkpoint not replicated |
| "Human label = binary MIC assay" misread | Schematic arm label reads *contrastive Good/Bad* not *MIC binary* |
| Legend overload | No legend box; colour identity via direct x-axis labels only |
