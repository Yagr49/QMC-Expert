PROTOCOL.md
# Matched partial MolFormer fine-tuning

Written before this experiment's training and outcomes. This is an exploratory
extension of inspected v9–v11 results, not a confirmatory preregistration.

## Intervention and fixed conditions

Use the archived matched-pooled panel: 681 molecules, 111 cation-scaffold groups,
96 final human Good calls and 4,938 underlying MIC records. Use identical ordered
canonical full-salt SMILES, cations and scaffolds for every supervision arm.
Exclude every evaluation cation, including counterion variants, from source
training and validation. Source and target scaffolds may overlap; the source
validation split and the individual target CV folds are scaffold-disjoint.

Reuse GroupShuffleSplit(test_size=0.15, random_state=1729), yielding 377 training
and 304 validation molecules. Validation is diagnostic, without early stopping,
checkpoint selection or hyperparameter selection. Do not train on its labels.
Reuse v10 target_folds.csv exactly: QAC-104 and Q-HERO-405 scaffold 5-fold CV;
OOD-17 uses a decoder trained on QAC-104. Target MIC enters only the training
fold of a refitted decoder, never source representation training.

Load ibm/MoLFormer-XL-both-10pct at revision
7b12d946c181a37f6012b9dc3b002275de070314 with its pinned custom code. Retain the
768-dimensional pooled representation and scalar linear head with dropout 0.1.
Freeze embeddings and encoder layers 0–3; train layers 4–11, the pooler and
scalar head. This is partial backbone fine-tuning, not full fine-tuning, LoRA or
the frozen-feature MLP. Record actual trainable parameter counts and names.
Use float32, deterministic feature maps, right padding to 202 tokens, and audit
all source/target lengths without truncation before fitting.

Six arms: human binary; continuous pooled log2 MIC; binary pooled MIC;
shuffled human; shuffled continuous MIC; shuffled binary MIC. Binary MIC cutoff
is the source-training MIC quantile corresponding to human training-positive
prevalence; ties can change actual prevalence. Standardise continuous targets
using only source training (population SD), invert scaling for direct predictions.
Shuffle source-training labels only using RNG 100000 + seed, preserving their
multiset. Keep diagnostic validation labels unshuffled.

Five paired seeds 0–4. Within each seed, match backbone/scalar-head initial
weights, minibatch permutations and stochastic seed across all six arms.
AdamW lr 3e-5, weight decay 0.01; OneCycleLR maximum lr 3e-5, pct_start 0.1;
batch size 32, gradient norm clip 1, 30 fixed epochs = 360 updates per arm.
Use the final checkpoint. These matched budgets do not imply equally optimal
hyperparameters for different objectives. Record all epoch losses, update counts,
initialisation and minibatch hashes, transformed-label hashes, checkpoint hashes,
dependencies, model revision and input/fold checksums.

## Evaluation and controls

Primary: Q-HERO-405 RMSE (log2 micromolar) with the same CatBoost decoder as
v9/v10: 300 iterations, depth 5, lr 0.05, seed 1729, four CPU threads. Secondary
R², QAC-104 and OOD-17. Compare real human vs shuffled human, human vs raw
pretrained features, human vs continuous MIC, and human vs binary MIC. Include
quantitative real-vs-shuffled and quantitative-vs-raw contrasts. Raw MolFormer is
re-encoded in this environment and audited against archived features; retain both
raw predictions if numerical differences are material. Also compare to the
archived five-seed frozen-feature MLP on the same panel/folds, clearly identifying
the different architecture and training schedule.

Complementary direct transfer: keep each source-trained scalar head; no target
fitting or recalibration. Report rank agreement with target log2 MIC (negative
Spearman for Good logits, positive for numerical predictions), and target-median
AUC as a secondary descriptive metric. Report raw R²/RMSE only for continuous
MIC heads. Shuffled heads supply direct-transfer null controls. An untrained
scalar head is not an activity predictor and has no meaningful concentration

PROTOCOL_IMPLEMENTATION_NOTE.md
# Implementation clarification during the run, 2026-10-11

The original PROTOCOL.md remains immutable and its checksum remains in the run
manifest. Inspection of the pinned MolFormer implementation during execution
identified an imprecise description and a checkpoint-storage limitation:

* `deterministic_eval=True` fixes attention feature maps **in evaluation**. Native
  MolFormer refreshes the random orthogonal feature-map buffers on each training
  forward pass even when the deterministic flag is true. The actual experiment
  retains this native stochastic training behaviour; paired seeds and identical
  forward-call/minibatch schedules match the draws across supervision arms.
  No model behaviour, optimisation setting, dataset or evaluation rule is changed.
* The original saved checkpoints contain trainable parameters and source-target
  transforms, but omit the final refreshed feature-map buffers. They remain as
  originally written, with their original hashes. A separate reconstruction step
  replays the paired training-forward RNG schedule, records final persistent
  buffers and writes complete reconstruction checkpoints to another directory.
  Each reconstruction must reproduce saved target embeddings and direct scores
  before being accepted. Its checksums and discrepancies are archived separately.

Manuscript descriptions use the verified distinction between stochastic training
and deterministic evaluation. The reconstruction script changes storage, not
training, predictions or reported metrics. The original checkpoint and prediction
files are never overwritten. This note is an implementation audit, not a
post-outcome change to a scientific hypothesis or hyperparameter choice.

def sha(path): return hashlib.sha256(Path(path).read_bytes()).hexdigest()
def object_sha(value): return hashlib.sha256(json.dumps(value, sort_keys=True).encode()).hexdigest()
def weights_sha(net):
    h = hashlib.sha256()
    for name, tensor in net.state_dict().items():
        h.update(name.encode()); h.update(tensor.detach().cpu().numpy().tobytes())
    return h.hexdigest()
def write_json(path, value):
    tmp = Path(str(path) + '.tmp'); tmp.write_text(json.dumps(value, indent=2, default=str)); tmp.replace(path)


class Net(nn.Module):
    def __init__(self, backbone):
        super().__init__(); self.enc = backbone; self.drop = nn.Dropout(.1); self.fc = nn.Linear(768, 1)
    def embed(self, **kw): return self.enc(**kw).pooler_output
    def forward(self, **kw): return self.fc(self.drop(self.embed(**kw))).squeeze(-1)


def load_net(seed, device):
    torch.manual_seed(seed); np.random.seed(seed)
    enc, loading = AutoModel.from_pretrained(MODEL, revision=REVISION,
        code_revision=REVISION, trust_remote_code=True, deterministic_eval=True,
        output_loading_info=True)
    # AutoModel intentionally omits the pretrained masked-language-model head.
    allowed_unused = {'lm_head.decoder.weight', 'lm_head.transform.LayerNorm.bias',
        'lm_head.transform.LayerNorm.weight', 'lm_head.transform.dense.bias',
        'lm_head.transform.dense.weight'}
    if (loading['missing_keys'] or set(loading['unexpected_keys']) - allowed_unused
            or loading['mismatched_keys'] or loading.get('error_msgs')):
        raise RuntimeError(('backbone loading mismatch', loading))
    for module in enc.modules():
        if hasattr(module, 'deterministic'): module.deterministic = True
    net = Net(enc)
    for name, p in net.enc.named_parameters():
        if name.startswith('embeddings') or any(f'layer.{i}.' in name for i in range(4)):
            p.requires_grad = False
    return net.to(device), loading


def tokenise(tokenizer, smiles):
    return tokenizer(list(smiles), padding='max_length', truncation=False,
                     max_length=202, return_tensors='pt')


@torch.no_grad()
def outputs(net, tokens, device, batch_size=32):
    net.eval(); reps = []; scores = []
    for start in range(0, len(tokens['input_ids']), batch_size):
        batch = {k: v[start:start + batch_size].to(device) for k, v in tokens.items()}
        emb = net.embed(**batch)
        reps.append(emb.float().cpu().numpy()); scores.append(net.fc(emb).squeeze(-1).float().cpu().numpy())
    return np.vstack(reps), np.concatenate(scores)


def decoder_predict(xtr, ytr, xte):
    model = CatBoostRegressor(iterations=300, depth=5, learning_rate=.05,
        random_seed=1729, thread_count=4, verbose=False, allow_writing_files=False)
    model.fit(xtr, ytr); return model.predict(xte)


def evaluate(reps, targets, folds):
    result = {}
    for name in TARGETS[:2]:
        d = targets[name]; pred = np.zeros(len(d))
        for tr, te in folds[name]:
            pred[te] = decoder_predict(reps[name][tr], d.y.values[tr], reps[name][te])
        result[name] = pred
    result['OOD-17'] = decoder_predict(reps['QAC-104'], targets['QAC-104'].y.values, reps['OOD-17'])
    return result

reconstruct_checkpoints.py
"""Recover final native feature-map buffers and independently reproduce outputs.

Training checkpoints and predictions remain immutable. Accept reconstructed
checkpoints only after numerical agreement with both embeddings and direct heads.
"""
from pathlib import Path
import argparse,json,time
import run_matched_finetuning as ft
import numpy as np
import pandas as pd
import torch
from sklearn.model_selection import GroupShuffleSplit

ROOT=Path(__file__).resolve().parent

def main():
    ap=argparse.ArgumentParser();ap.add_argument('--results',type=Path,default=ROOT/'results')
    ap.add_argument('--seeds',nargs='+',type=int,default=list(range(5)));a=ap.parse_args()
    r=a.results;out=r/'reproducible_checkpoints';out.mkdir(exist_ok=True)
    torch.set_num_threads(4);torch.backends.cuda.matmul.allow_tf32=False;torch.backends.cudnn.allow_tf32=False
    torch.use_deterministic_algorithms(True,warn_only=True);device=torch.device('cuda')
    torch.cuda.set_per_process_memory_fraction(.30)
    source=pd.read_csv(ROOT/'data/matched-pooled_expert.csv')
    tr,va=next(GroupShuffleSplit(n_splits=1,test_size=.15,random_state=1729).split(source,groups=source.scaffold))
    tokenizer=ft.AutoTokenizer.from_pretrained(ft.MODEL,revision=ft.REVISION,code_revision=ft.REVISION,trust_remote_code=True)
    tokenizer.padding_side='right';tokens=ft.tokenise(tokenizer,source.can.iloc[tr])
    targets={n:pd.read_csv(ROOT/'data'/f'target_{n}.csv') for n in ft.TARGETS}
    target_tokens={n:ft.tokenise(tokenizer,d.can) for n,d in targets.items()}
    predictions=pd.read_csv(r/'direct_predictions.csv');train=pd.read_csv(r/'training.csv')
    records=[]
    for seed in a.seeds:
        started=time.time();net,loading=ft.load_net(seed,device)
        # Only shapes and the stochastic forward schedule determine feature-map
        # draws; no gradient or optimiser operation consumes a random draw.
        torch.manual_seed(300000+seed);generator=torch.Generator().manual_seed(200000+seed)
        net.train()
        with torch.no_grad():
            for epoch in range(30):
                order=torch.randperm(len(tr),generator=generator)
                for start in range(0,len(tr),32):
                    idx=order[start:start+32]
                    batch={k:v[idx].to(device) for k,v in tokens.items()}
                    net(**batch)
        state_names=set(net.state_dict())
        buffers={name:b.detach().cpu().clone() for name,b in net.named_buffers() if name in state_names}
        projection_count=sum('feature_map' in name and name.endswith('weight') for name in buffers)
        assert projection_count==12,(projection_count,list(buffers))
        for arm in ft.ARMS:
            original=r/'checkpoints'/f'{arm}_seed{seed}.pt'
            saved=torch.load(original,map_location='cpu',weights_only=False)
            digest=train.set_index(['arm','seed']).loc[(arm,seed)].checkpoint_sha256
            assert ft.sha(original)==digest
            combined=dict(saved['state_dict'],**buffers)
            missing=net.load_state_dict(combined,strict=False)
            assert not missing.unexpected_keys
            frozen={name for name,p in net.named_parameters() if not p.requires_grad}
            assert set(missing.missing_keys)==frozen,(set(missing.missing_keys)-frozen)
            binary=arm.startswith('expert') or arm.startswith('quant-binary')
            checks=[]
            for name,tok in target_tokens.items():
                emb,score=ft.outputs(net,tok,device)
                archived_emb=np.load(r/'representations'/f'{arm}_seed{seed}_{name}.npy')
                sub=predictions[(predictions.arm==arm)&(predictions.seed==seed)&(predictions.target==name)].set_index('can').loc[targets[name].can]
                restored_score=score if binary else score*saved['target_sd']+saved['target_mean']
                feature_diff=float(np.max(np.abs(emb-archived_emb)))
                score_diff=float(np.max(np.abs(restored_score-sub.score.values)))
                assert np.allclose(emb,archived_emb,rtol=1e-5,atol=1e-6),(seed,arm,name,'embedding',feature_diff)
                assert np.allclose(restored_score,sub.score.values,rtol=1e-5,atol=1e-6),(seed,arm,name,'score',score_diff)
                checks.append(dict(target=name,max_feature_difference=feature_diff,max_score_difference=score_diff))
            path=out/f'{arm}_seed{seed}.pt';assert not path.exists()
            torch.save(dict(saved,state_dict=combined,buffer_replay='paired native forward RNG schedule; verified against original outputs'),path)
            records.append(dict(arm=arm,seed=seed,original_checkpoint_sha256=digest,
                reconstructed_checkpoint_sha256=ft.sha(path),checkpoint_file=str(path),
                persistent_buffer_count=len(buffers),feature_map_count=projection_count,
                max_feature_difference=max(c['max_feature_difference'] for c in checks),
                max_score_difference=max(c['max_score_difference'] for c in checks)))
            pd.DataFrame(records).to_csv(r/f'checkpoint_reconstruction_seeds_{"_".join(map(str,a.seeds))}.csv',index=False)
            print('REPRODUCED',seed,arm,checks,flush=True)
        del net;torch.cuda.empty_cache();print('SEED BUFFER REPLAY',seed,round(time.time()-started,1),'seconds',flush=True)
    ft.write_json(r/f'checkpoint_reconstruction_seeds_{"_".join(map(str,a.seeds))}.json',dict(complete=True,
        script_sha256=ft.sha(__file__),implementation_note_sha256=ft.sha(ROOT/'PROTOCOL_IMPLEMENTATION_NOTE.md'),
        original_checkpoints_preserved=True,checkpoints=len(records),max_feature_difference=max(d['max_feature_difference'] for d in records),
        max_score_difference=max(d['max_score_difference'] for d in records)))

if __name__=='__main__':main()
