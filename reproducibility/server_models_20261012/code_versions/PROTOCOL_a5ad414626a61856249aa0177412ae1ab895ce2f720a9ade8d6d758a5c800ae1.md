## Независимые повторы существующих экспериментов

1. v14: 105 солей QAC, 103 катиона, четыре конечные точки, log2(mg/L),
   неизменные cation-grouped folds и отдельно scaffold-grouped folds, OOD-17.
   CatBoost и кэшированные текстовые векторы с исходными параметрами.
2. v10: повтор source-обучения маленьких MLP на замороженных признаках
   MolFormer, c3-MolFormer, ChemBERTa-100M и ChemFM-1B. Два matched-панеля,
   пять seeds, исходные shuffled/untrained контроли, Ridge и CatBoost.
   Эти повторы сохраняют исторический target QAC-104/Q-HERO/OOD для проверки
   воспроизводимости прежнего расчёта. Они не заменяют основной QAC-105 тест.
   Извлечение исходных frozen признаков использует проверенный архив.
3. v10: повтор контекстного сравнения экспертных меток, pooled MIC и точного
   S. aureus MIC на общей source-панели из 529 молекул.
4. v12: полное повторное matched partial fine-tuning: 6 arms × 5 seeds,
   30 эпох, те же train/validation IDs, порядок батчей, версия backbone и
   гиперпараметры. Единственное изменение копии скрипта: checkpoint содержит
   все mutable buffers вместе с обученными параметрами. Обучение не меняется.
5. Из НОВЫХ checkpoint заново кодируются ВСЕ 105 QAC и 17 OOD молекул;
   сравниваются векторы, затем повторяются обе схемы v14 target-проверки.
   Исторические legacy checkpoints с source overlap не входят в этот блок.

## Новые архитектурные сравнения

Chemprop 2.3.1 D-MPNN: 4-target regression, полный canonical salt SMILES,
hidden size 300, depth 3, mean aggregation, без batch normalization,
100 фиксированных эпох, seeds 0/1/2; target scaler обучается только на train.
Последняя эпоха, без выбора checkpoint по внешнему fold или OOD. Отдельные
5-fold проверки по катионам и каркасам; OOD fit использует все 105 QAC.

AutoGluon 1.6.3, TabPFN 9.1.0 и TabFM (зафиксированный при установке Git SHA)
проверяются на одинаковых пяти представлениях: RDKit descriptors,
raw MolFormer, human partial-FT seed0, quantitative-continuous partial-FT seed0,
quantitative-binary partial-FT seed0. Это сравнение алгоритмов на одном source
seed, а не повтор пяти-seed causal эксперимента. Все представления с 768
признаками уменьшаются до PCA-32, обученной только на outer train.
RDKit признаки проходят train-only imputation/variance filtering/scaling.
CatBoost на тех же преобразованных признаках служит контрольным декодером.
Отдельная регрессия для каждой из четырёх конечных точек.

AutoGluon: 60 секунд на endpoint fit, RF/XT/GBM/CAT, без stacking/bagging,
inner validation с разбиением по катиону либо каркасу согласно outer схеме.
После выбора модели refit_full использует только outer train. OOD не
передаётся в fit/validation. Ошибка refit сохраняется явно.
TabPFN: поддерживаемая версия публично доступных regression weights,
4 estimators, фиксированный random state, CUDA. Версия весов и путь
сохраняются в manifest; недоступные gated weights отмечаются как ошибка.
TabFM: официальный JAX backend, CPU, 4 estimators, max_num_rows=None
(все строки outer train), float32 и JAX attention. Параметры контекста
отражаются в manifest. Git SHA: fbb665569425fd2f490c6576b3af967876fe11ff.

Все модели используют фиксированные folds из v14, полный salt SMILES и
log2(mg/L). Сохраняются предсказания с compound IDs, task, fold, qualifier,
версии пакетов, hashes кода/входов, параметры и время каждого fit.
Показатели: RMSE, MAE, R² и Spearman по каждой точке и pooled.
OOD: 67 точных значений; Ec_MBC IT-505 >500 mg/L сохраняется как bound и
исключается из exact-value метрик. Единственная OOD fit на full QAC
не дублируется между двумя CV-схемами.

Результаты новых моделей нельзя использовать для изменения folds,
подбора по OOD или утверждения, что human supervision обязательно лучше.
Несовпадения с архивами публикуются как находки проверки.

JSON очередей: status/{gpu,core_cpu,tabular_cpu}.json.

проверенные outputs неизменяемы, повтор требует нового каталога.
